## Implementation

### Method 1: Direct URL Replacement
Replace SVG files with direct Unsplash URLs in HTML:

```html
<!-- Before -->
<img src="assets/images/hero-bathroom.svg" alt="Bathroom">

<!-- After -->
<img src="https://images.unsplash.com/photo-1552321554-5fefe8c9ef14?w=1920&h=900&fit=crop" alt="Bathroom">
```

### Method 2: Download and Host
Download images and host them locally:

1. Download images from Unsplash
2. Optimize with TinyPNG or Squoosh
3. Convert to WebP format
4. Replace SVG files in assets/images/
5. Update HTML references

### Method 3: CDN with Unsplash Source
Use Unsplash Source for dynamic images:

```html
<img src="https://source.unsplash.com/1920x900/?luxury,bathroom" alt="Bathroom">
```

---

## Recommendations

1. **Use Method 2** for production (download and host locally)
2. **Optimize images** to under 200KB each
3. **Convert to WebP** for better compression
4. **Add lazy loading** for below-the-fold images
5. **Add srcset** for responsive images
6. **Add alt text** for accessibility
7. **Add blur placeholders** for better loading experience

---

## Notes

- Unsplash images are high-quality but may be large
- Consider using a CDN (Cloudinary, Imgix) for optimization
- Add proper caching headers for production
- Test images on slow connections
- Verify images work on all devices
